# Changelog

All notable changes to Liquid Notes are documented in this file. The project follows [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-07-29

### Added

- Adaptive light and dark palettes with macOS system-blue accents.
- Liquid Glass-inspired navigation, toolbars, sidebars, menus, and dialogs.
- Finder-like file navigation with original CSS folder and document marks.
- San Francisco, PingFang, and SF Mono font stacks with cross-platform fallbacks.
- Xcode-inspired multicolor syntax for editing and reading modes.
- Styling for Markdown content, Bases, Canvas, Graph, PDF, settings, and mobile layouts.
- Reduced-motion, increased-contrast, reduced-transparency, and solid-surface fallbacks.
- Dependency-free browser-rendered validation and a safe local installation script.
